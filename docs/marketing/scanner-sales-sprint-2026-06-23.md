## FAQ Objections

**Is this a pentest?**  
No. This is a lightweight public chatbot scan and review. It helps prioritize obvious LLM app gaps before deciding whether a formal pentest or AI security assessment is needed.

**Do you need credentials or code access?**  
No for the first pass. The sprint is scoped to public URLs and browser-visible posture unless a separate approved scope is agreed.

**Will this touch production data?**  
No. The manual-send sprint should stay non-invasive and public-chatbot only. Do not submit destructive payloads, spam forms, bypass access controls, or test anything that could disrupt service.

**What do we get?**  
A concise risk note, severity order, recommended fixes, and a retest checklist.

**Who is this for?**  
Small SaaS teams, agencies, founders, and operators with public chatbots or AI assistant flows who need a fast confidence check before launch, sales review, customer due diligence, or audit prep.

**What if we already use a scanner?**  
This can still help translate scanner-style findings into business-readable priorities and manual next actions.

**Can we use the report for compliance?**  
Use it as internal preparation only unless reviewed by your compliance, legal, or security owner. It is not a certification, attestation, or formal audit.
